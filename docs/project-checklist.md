## Reading + Reproduction: yêu cầu môn

- [ ] Paper được đăng ký/chấp nhận trên Moodle.
- [ ] Một public repo toàn học kỳ, có code/docs/notebooks nếu dùng và commit history.
- [ ] Full scope được nêu trong deck; toàn bộ thí nghiệm chính trên cùng/equivalent datasets.
- [ ] Phương pháp tự hiện thực; phần tái sử dụng có nguồn.
- [ ] Chạy code tác giả công khai và khoanh vùng pipeline divergence.
- [ ] Python >=3.9, dependencies được ghi, phần ngoài scientific stack có lý do.
- [ ] Seed cố định, docstrings quan trọng, hướng dẫn setup/chạy end-to-end.
- [ ] Tải và reconstruct dữ liệu tự động từ HF/Kaggle; nếu thiếu bản phù hợp, nhóm chuẩn bị/upload hợp lệ.
- [ ] Một W&B project public, mỗi experiment có config/metrics/plots/run links.
- [ ] README có experiment -> script/notebook -> W&B run -> nhận xét.
- [ ] Paper vs reproduction, relative deviation khi áp dụng được và giải thích nguyên nhân.
- [ ] Một PPTX 20-40 slides kể cả appendix, dưới 20 MB.
- [ ] Mỗi slide có notes <=500 từ, giải thích lập luận.
- [ ] Slide trực quan; không đoạn văn dài/raw source code.
- [ ] Hình tự vẽ/tái dựng, citation IEEE ở chân slide, không References slide riêng.
- [ ] Có motivation tự tạo, >=2 predecessors với consequences, novelty, notation, pipeline, components, theory/complexity.
- [ ] PPTX và link repo nộp riêng trên Moodle.
